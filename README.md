# PowerClient

Built Fabric client archive and full Java source.

## Download
Download [`donut-client-1.0.0-complete.zip`](./donut-client-1.0.0-complete.zip) from this repository, then extract it.

The archive includes:
- `build/libs/donut-client-1.0.0.jar` — distributable mod JAR
- `build/libs/donut-client-1.0.0-sources.jar` — source archive
- `build/devlibs/donut-client-1.0.0-dev.jar` — development JAR
- `src/` — complete Java source
- Gradle build configuration
